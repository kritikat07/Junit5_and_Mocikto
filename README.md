**JUnit 5**
JUnit is a testing framework used to write and execute test cases.
It provides annotations such as @Test, @BeforeEach, and assertions such as assertEquals() and assertThrows().

**Mockito**
Mockito is a mocking framework used to create fake dependencies for testing.
It provides @Mock, @InjectMocks, when(), thenReturn(), and verify()

**Spring Boot Test**
Spring Boot provides testing support through spring-boot-starter-test, including JUnit Jupiter, Mockito, Spring Test, and AssertJ.
